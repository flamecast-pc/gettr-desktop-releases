Before you install

  • macOS: these builds are ad-hoc signed and not notarized by Apple, so opening the app normally reports an unidentified developer. Right-click the app in Finder and choose Open, or run xattr -dr com.apple.quarantine "/Applications/GETTR Desktop.app".
  • Windows: the installer is not Authenticode signed yet, so SmartScreen reports an unknown publisher. Choose More info → Run anyway to continue.
  • On Apple Silicon, take the Apple Silicon build. The Intel build runs under Rosetta, but it is slower and has no beauty filter.

Checksums and earlier versions are on the Releases page. The app updates itself, so you will not need to come back here.
